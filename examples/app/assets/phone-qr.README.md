# Phone QR asset

Encodes exactly `https://chatppg.com/ppg-js-demo`.

Generated at implementation time with Python `qrcode` 8.2 (BSD-3-Clause), error correction Q, automatic version, and a four-module white quiet zone on every side. The SVG is a static matrix; no encoder code or runtime dependency is distributed. Keep its white background and quiet zone intact, and keep all decorative filters outside the image.
